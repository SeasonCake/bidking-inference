# Project relationship

`bidking-inference` is a public, domain-neutral mathematical companion to the private
BidKing calculator project. Its implementation and synthetic fixtures were newly
written for public use; the repository does not mirror or publish the private product.

Reusable engineering workflows learned while building and maintaining BidKing are
published separately in
[`evidence-first-agent-skills`](https://github.com/SeasonCake/evidence-first-agent-skills).
That companion covers evidence levels, verification, CLI contracts, architecture
surveys, and fresh-agent compatibility.

Neither repository contains private source history, production topology, customer
diagnostics, credentials, captured traffic, proprietary game tables, or third-party
game assets.
