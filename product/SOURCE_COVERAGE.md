# Source coverage

This export includes the owner-selected modern source snapshot: Python engine and
simulation, capture/OCR/protocol adapters, state and lifecycle, Tk and analytical
surfaces, activation/renewal, collector/readers/indexing, Rust source, operator/build
tools and test source. The exact files and exported hashes are in SOURCE_MANIFEST.json.

The source discovery inventory selected 1,128 paths. Three root dependency files were
added. One private match-classification input was excluded. Further public-use files
provide documentation, an offline example and bounded tests. The manifest distinguishes
original/adapted source from new export support.

The endpoint JSON supplied here is a newly written fictional configuration example,
not a production configuration export. Its `.invalid` origins preserve the documented
schema and let offline fallback tests run without connecting to a live service.

Source adaptations are intentionally separate from inference changes:

- replace personal profiles/contact details and production hostnames with examples;
- replace identifying numeric session labels consistently, retaining their relationships;
- require an explicit host for remote collection tools;
- use a loopback collector default and require a nonempty key for external binding;
- validate HTTP body lengths before reading, retaining each route's response contract;
- update two historical test doubles for the existing identity-store keyword.

The HTTP parsing correction is a source change. Publication of this checkout says
nothing about what version or settings any independently operated service is running.

The existing stable v0.1.0 package, 56-file historical source snapshot, seven historical
data files, research sources and approved documentation images are preserved.

## External inputs

Current game tables and art, player captures, private sample classifications and databases,
local model/calibration files, pet/UI assets, dependency binaries, generated build stages,
signing/data/activation keys, encrypted configuration and private operational history are
not included. Their names in a build manifest do not supply the bytes or rights.

The private repository's Git history and working-tree diagnostics are not copied.
The public repository continues its own existing history. The source export is intended
for study, modification and self-hosting with operator-supplied inputs, not as a claim
that an official encrypted Windows ZIP can be recreated from public source alone.

## Tests and build scope

The offline quick start and recorded test selection use fictional input.
Other retained regression tests can require excluded catalogue/replay/build inputs.
Missing-input failures and untested native/UI/package flows remain explicit in
VERIFICATION.md. The root package's portable verifier is independent from these
product/runtime checks.
