# BidKing 0.3.5：研发进展

[English](DEVELOPMENT_STATUS.md) · [返回首页](../README.md)

记录日期：2026-09-07。这里说明正在推进的工作，不是发布说明或可下载候选。

0.3.5 的目标是让估值、个人报价偏好、状态恢复与使用流程更一致。当前仍处于源码修订和验证阶段；
可下载 Windows 成品仍是[0.3.4-hotfix1](https://github.com/SeasonCake/bidking-inference/releases/tag/product-v0.3.4-hotfix1)。
公开 Python 推断包继续保持独立的 `v0.1.0` 版本线，没有随产品目标改版号。

## 正在推进什么

| 方向 | 希望改善的体验 | 本次记录时的进展与未完事项 |
| --- | --- | --- |
| 联合约束与计算正确性 | 多种揭示信息共同约束候选，保持估值语义一致 | 多轮聚焦源码修订与独立审查已有结果；真实信息资格、未覆盖的现场语义与统计校准仍单列，不宣称全英雄精度完成 |
| 基础报价偏好 | 保存个人方案，在保留原始估值的基础上调整三档参考 | 结算时间关联修订和部分保存、重开、恢复默认流程已验证；实际手填路径与完整用户旅程仍在推进 |
| 激活恢复与换绑提示 | 更准确地区分本地恢复阶段，并清楚显示当前状态 | 本地恢复、提交失败分类及相关逻辑审查已有结果；完整实际激活、换绑与必要服务生效仍未完成 |
| 刷新与启动 | 降低无意义等待，让结果与当前会话一致 | 部分真实刷新链路和界面状态已核验，过期输入触发的重复计算正在继续修订验证；启动性能与整体端到端收益尚无完成结论 |
| 使用入口与说明 | 让帮助、店铺入口和相关说明更容易找到、彼此一致 | 店铺入口、部分说明与本地导出恢复流程已有核验；其它真实状态与最终成品仍需验证 |

局部源码通过检查，不代表整版已完成。候选构建、实际界面、打包、必要的服务变更与发布回读仍需
各自的证据。尚未提供0.3.5下载链接，也不在此承诺发布日期或未测的性能收益。

## 本次中间态更新的边界

本次只更新进展说明和可复用维护方法，没有更改公开推断包、现有下载或产品发布状态。
后续完整版本会在实际验证和交付闭合后单独说明；计划中的时间窗口不等于已经发布。
维护时保留已完成检查的适用范围，也保留后来发现的问题和仍缺的真实输入，避免反复重做或过早报喜。

## 现在可以复用的内容

- 本仓的[公开推断接口](PUBLIC_API.md)和[合成示例](../examples)：不需要私有产品或游戏环境。
- [观测完整性与版本资格案例](EVIDENCE_LIFECYCLE.zh-CN.md)：区分精确、部分和缺失观测，避免旧状态冒充当前证据。
- 配套[浏览器工作流](https://github.com/SeasonCake/evidence-first-agent-skills/tree/main/skills/browser-workflow)：
  按业务键编辑、保存前检查、结果未知先回读，避免把草稿或成功退出码当成保存完成。
- 配套[意图确认](https://github.com/SeasonCake/evidence-first-agent-skills/tree/main/skills/intent-checkpoint)：
  处理真正影响范围的选择，同时让已明确的工作继续。
- 配套[中间态维护与分享](https://github.com/SeasonCake/evidence-first-agent-skills/blob/main/docs/INTERIM_MAINTENANCE.zh-CN.md)：
  用日期、证据范围、未完项与下一动作组织定期检查，不把中间进展写成发布完成。
