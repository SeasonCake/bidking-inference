# BidKing 0.3.5：研发进展

[English](DEVELOPMENT_STATUS.md) · [返回首页](../README.md)

记录日期：2026-09-06。这里说明正在推进的工作，不是发布说明或可下载候选。

0.3.5 的目标是让估值、个人报价偏好、状态恢复与使用流程更一致。当前仍处于源码修订和验证阶段；
可下载 Windows 成品仍是[0.3.4-hotfix1](https://github.com/SeasonCake/bidking-inference/releases/tag/product-v0.3.4-hotfix1)。
公开 Python 推断包继续保持独立的 `v0.1.0` 版本线，没有随产品目标改版号。

## 正在推进什么

| 方向 | 希望改善的体验 | 本次记录时的进展与未完事项 |
| --- | --- | --- |
| 联合约束与计算正确性 | 多种揭示信息共同约束候选，保持估值语义一致 | 一批聚焦源码检查与独立审查已完成；不能据此宣称全英雄精度或价格校准已完成 |
| 基础报价偏好 | 保存个人方案，在保留原始估值的基础上调整三档参考 | 已有源码实现；与结算记录的时间关联仍在修订验证，真实界面尚待检查 |
| 激活恢复与换绑提示 | 更准确地区分本地恢复阶段，并清楚显示当前状态 | 相关源码与逻辑审查已推进；完整用户流程、界面和服务部署仍待验证 |
| 刷新与启动 | 降低无意义等待，让结果与当前会话一致 | 一项刷新调度修订已通过聚焦检查；完整刷新占用、启动性能及现场端到端延迟尚未闭合 |
| 使用入口与说明 | 让帮助、店铺入口和相关说明更容易找到、彼此一致 | 源码和装配说明已同步；仍需真实界面及最终成品核验 |

局部源码通过检查，不代表整版已完成。候选构建、实际界面、打包、必要的服务变更与发布回读仍需
各自的证据。尚未提供0.3.5下载链接，也不在此承诺发布日期或未测的性能收益。

## 现在可以复用的内容

- 本仓的[公开推断接口](PUBLIC_API.md)和[合成示例](../examples)：不需要私有产品或游戏环境。
- [观测完整性与版本资格案例](EVIDENCE_LIFECYCLE.zh-CN.md)：区分精确、部分和缺失观测，避免旧状态冒充当前证据。
- 配套[浏览器工作流](https://github.com/SeasonCake/evidence-first-agent-skills/tree/main/skills/browser-workflow)：
  按业务键编辑、保存前检查、结果未知先回读，避免把草稿或成功退出码当成保存完成。
- 配套[意图确认](https://github.com/SeasonCake/evidence-first-agent-skills/tree/main/skills/intent-checkpoint)：
  处理真正影响范围的选择，同时让已明确的工作继续。
